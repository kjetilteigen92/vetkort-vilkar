4. Use of Artificial Intelligence (AI)

VetKort provides features that automatically extract text from images and documents using Optical Character Recognition (OCR).

When you use this feature, the selected file is temporarily transmitted to our AI provider (OpenAI) for processing.

The data is used solely to perform the requested task and is not used by us for marketing purposes.

AI processing only takes place when you actively choose to use the feature.

# Radera ditt VetKort-konto

Hos VetKort har du full kontroll över dina personuppgifter.

## Radera ditt konto i appen

Du kan när som helst radera ditt konto direkt i VetKort-appen.

1. Öppna VetKort.
2. Gå till **Mitt konto**.
3. Tryck på **Radera konto**.
4. Bekräfta raderingen.

När ditt konto raderas tas även all tillhörande data permanent bort från våra system.

Detta inkluderar:

- Husdjur
- Journaler
- Vaccinationer
- Läkemedel
- Dokument
- Bilder
- Viktregistreringar
- Sparade veterinärkliniker
- Övriga kontorelaterade uppgifter
